# J-Link 디버그 도구

동작 중인 Sullivan 1.5 펌웨어에 J-Link로 붙어 RTT 글, DMIC 입력, vMag를 PC 창으로 보고, 사인이나 WAV를 마이크 입력 자리에 넣는 도구다. 코어를 멈추거나 리셋하지 않는다.

> **주의**: 펌웨어를 내려받는(굽는) 동안에는 도구를 켜 두지 않는다. J-Link는 한 번에 한 프로그램만 쓸 수 있고, 내려받기가 끊기면 보드가 부팅하지 못할 수 있다. RTT Viewer, IDE 디버거와도 함께 쓰지 않는다.

## 설치

| 필요한 것 | 확인한 판 |
|---|---|
| Windows | 10 |
| 파이썬 (64비트) | 3.11.0 |
| 패키지 `pylink-square`, `numpy`, `matplotlib` | 2.0.1, 2.4.6, 3.11.2 |
| SEGGER J-Link 소프트웨어 | V8.64 |

1. 파이썬 64비트를 설치한다. 설치할 때 **Add python.exe to PATH**를 체크한다.
2. 패키지를 설치한다: `python -m pip install -r src/requirements.txt`
3. SEGGER J-Link Software and Documentation Pack을 설치한다.
4. 펌웨어 환경을 설정한다. 방법은 [`docs/가이드/펌웨어_환경_설정.md`](docs/가이드/펌웨어_환경_설정.md), 넣을 파일은 `firmware/`에 있다.

설정 파일은 `src/tdc_debug_jlink.ini`다. 보통은 고칠 것이 없다.

| 키 | 고치는 때 |
|---|---|
| `serial` | J-Link가 둘 이상 꽂혀 있을 때. 쓸 J-Link 번호를 적는다 |
| `dll_path` | J-Link 소프트웨어를 여러 판 깔았을 때. 쓸 `JLink_x64.dll` 경로를 적는다 |
| `speed_khz` | 통신 오류가 날 때 낮춘다. 기본 12000, 상한 15000 |

## 사용법

`src/run_tdc_debug_jlink.bat`를 더블클릭한다. 터미널 창이 열리고 J-Link에 붙는다. 터미널 창을 닫으면 끝난다.

- 왼쪽 **RTT 터미널**: 펌웨어의 RTT 글이 나온다. 화면을 클릭하고 키를 누르면 한 글자씩 펌웨어로 보낸다.
- 오른쪽 **pylink 터미널**: 아래 칸에 명령을 쓰고 Enter를 누른다.
- 연결되면 오른쪽에 `디버그 블록 요약: PC 툴 2개 중 2개 일치`가 나온다. 다른 글이 나오면 위 문서의 "5. 확인"을 본다.

| 명령 | 하는 일 |
|---|---|
| `help` | 명령 목록 |
| `status` | 연결, 켠 기능 |
| `capture dmic on` / `off` | DMIC 창을 열어 입력 파형과 레벨을 본다 (펌웨어가 라이브 자극 모드일 때) |
| `capture vmag on` / `off` | vMag 창을 열어 밴드 32개를 본다 |
| `capture ifft on` / `off` | IFFT 창을 열어 기존 DAC 출력과 IFFT 후 DAC 출력을 위아래로 본다 |
| `save on` / `off` | 가져온 데이터를 `src/logs/`에 저장한다 (DMIC는 WAV, vMag는 CSV, IFFT는 2채널 WAV) |
| `read 주소 [개수]` | 32비트 워드 읽기. 예: `read 0x21010000 4` |
| `log N` | 종합 로그 간격(초) |
| `perf` | 처리 시간 측정 |

놓친 샘플이 있을 때만 `[1 s] dmic 놓침 12 ms` 같은 줄이 나온다. 아무 줄도 나오지 않는 것이 정상이다.

**주입 (DMIC 창)**: 창 아래 줄에서 원천(사인 1, 2, 4, 6 kHz 또는 WAV 파일)을 고르고 `주입 켜기`를 누른다. 펌웨어가 라이브 자극 모드일 때 마이크 입력 대신 들어간다. WAV는 16 kHz 모노 정수 PCM만 된다. WAV의 최대 크기가 입력 최대가 되므로, 크게 만든 파일은 사인 원천(약 -50 dBFS)보다 훨씬 크게 들어간다.

**vMag 창**: 보기(실시간, 구간 평균, 최근 평균)를 고른다. `캡처`는 지금 곡선을 고정하고(5개까지), `캡처 삭제`는 체크된 것만 지운다.

**IFFT 창**: 위는 기존 DAC 출력, 아래는 IFFT 후 DAC 출력이다(같은 크기, 같은 눈금). IFFT 모드는 RTT 터미널에서 `i` 키로 켜고 끈다. 흐르는 동안에는 3초 전체가 보인다. `멈춤`을 누르거나 좁은 구간(300 ms, 30 ms, 10 ms)을 고르면 그림이 멈추고, 아래 막대를 끌거나 그래프를 클릭해 보는 자리를 옮긴다. `이어서`로 다시 흐른다. 지연 측정은 잡음처럼 주기가 없는 소리에서만 된다.
