# 펌웨어 환경 설정

J-Link 디버그 도구를 쓰려면 Sullivan 1.5 펌웨어에 파일 4개를 복사하고, 파일 3개에 코드를 넣은 뒤 다시 빌드한다.

## 1. 파일 복사

| 복사할 파일 | 넣을 폴더 |
|---|---|
| `firmware/CFX/tdc_debug_jlink.h` | `Sullivan1_5__CFX/systemControl/` |
| `firmware/CFX/tdc_debug_jlink.c` | `Sullivan1_5__CFX/systemControl/` |
| `firmware/CM3/tdc_debug_jlink_notify.h` | `Sullivan1_5__CM3/Cortex-M3-src/systemControl/` |
| `firmware/CM3/tdc_debug_jlink_notify.c` | `Sullivan1_5__CM3/Cortex-M3-src/systemControl/` |

## 2. CFX 코드 넣기

### `Sullivan1_5__CFX/systemControl/main.h`

include 목록에 넣는다.

```c
#include <tdc_debug_jlink.h>
```

### `Sullivan1_5__CFX/systemControl/main.c`

세 곳에 넣는다.

**(1)** `normal_init()` 함수

```c
#if TDC_DEBUG_JLINK_ENABLE
    tdc_debug_jlink_init();
#endif
```

**(2)** `normal_loop()` 함수의 `if (g_pcm_mode == PcmBitStream_Mode_LiveStimulation)` 안. `audio_mix_*` 함수가 DMIC 입력 FIFO를 읽은 다음, `g_interrupt_flags.function_chain0 = 0; /* HEAR_FC_agc_preprocessing */` 줄 위

```c
#if TDC_DEBUG_JLINK_ENABLE
                if (TDC_DEBUG_JLINK_AREA->dmic.dmic_enable != 0)
                {
                    tdc_debug_jlink_dmic(g_earpiece_adc_enabled);
                }
#endif
```

**(3)** `normal_loop()` 함수의 `else if (g_interrupt_flags.function_chain0 == 1)` 안, 맨 아래

```c
#if TDC_DEBUG_JLINK_ENABLE
            if (TDC_DEBUG_JLINK_AREA->vmag.vmag_enable != 0)
            {
                tdc_debug_jlink_vmag_capture();
            }
#endif
```

## 3. CM3 코드 넣기

### `Sullivan1_5__CM3/Cortex-M3-src/systemControl/initialize.c`

두 곳에 넣는다.

**(1)** include 목록

```c
#include "tdc_debug_jlink_notify.h"
```

**(2)** `enable_CFX_trigger_for_iteration()` 함수

```c
#if TDC_DEBUG_JLINK_ENABLE
    tdc_debug_jlink_notify_init();
#endif
```

## 4. 빌드

`Sullivan1_5__CFX`, `Sullivan1_5__CM3` 프로젝트를 각각 Clean 한 뒤 Build 한다. 프로젝트 설정과 링커 파일은 고치지 않는다.

## 5. 확인

펌웨어를 올리고 `src/run_tdc_debug_jlink.bat`를 실행한다. 오른쪽 pylink 터미널에 아래 줄이 나오면 끝이다.

```
디버그 블록 요약: PC 툴 2개 중 2개 일치
```

| 다른 줄이 나오면 | 볼 것 |
|---|---|
| `디버그 블록 없음 (0x21010000 에 magic 없음, 읽은 값 …)` | `Sullivan1_5__CFX/systemControl/main.c`의 (1)이 들어갔는지, 새 펌웨어를 올렸는지 |
| `디버그 블록: DMIC(id 1) PC 툴과 불일치` 같은 줄 | 펌웨어 파일과 PC 도구의 판이 다르다. 이 저장소의 `firmware/`와 `src/`를 같은 판으로 맞춘다 |

## 끄기

넣은 코드를 빼고 빌드하려면 아래 두 값을 0으로 바꾸고 다시 빌드한다. 넣은 코드는 그대로 둔다. 두 값은 항상 같게 둔다.

| 파일 | 줄 |
|---|---|
| `Sullivan1_5__CFX/systemControl/tdc_debug_jlink.h` | `#define TDC_DEBUG_JLINK_ENABLE 1` |
| `Sullivan1_5__CM3/Cortex-M3-src/systemControl/tdc_debug_jlink_notify.h` | `#define TDC_DEBUG_JLINK_ENABLE 1` |
